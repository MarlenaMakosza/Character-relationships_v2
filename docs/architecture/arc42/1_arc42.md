## What is arc42?

arc42 is a template for documenting software and system architecture. It provides 12 sections covering everything from goals and constraints to building blocks, deployment, and risks — used only as needed, not as a checklist. The structure is technology- and process-agnostic, so it works equally well for a small side project and an enterprise system.

The value of arc42 is consistency: anyone familiar with the template knows where to look for context, decisions, and constraints without having to reverse-engineer the folder structure. Unused sections simply don't exist.
