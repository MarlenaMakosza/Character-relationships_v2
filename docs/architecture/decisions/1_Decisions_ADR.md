## What is an ADR?

An Architecture Decision Record (ADR) is a short document that captures a single architectural decision — the context that led to it, the options considered, and the rationale for the choice made. ADRs are written at the moment of the decision, when the reasoning is still fresh, and stored alongside the code so they evolve with the project.

The goal is not to document what was built, but why. When a new developer joins or a decision needs revisiting, ADRs answer the question that code alone cannot: why does it work this way and not some other way?
